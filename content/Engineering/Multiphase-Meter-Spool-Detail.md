## The Example: A Spool for a Multiphase Meter

A **spool** is a short, pre-fabricated section of pipe with **flanges on both ends**, built and pressure-tested in the shop, then bolted into a line in the field. This spool was designed as the host for a **multiphase meter** — the compact run that places the metering point exactly where it needs to sit.

### Why it needs its own section

A multiphase meter measures oil, water, and gas at the same time, without separating them first. But it only reads accurately when the flow reaching it is stable and developed. That means:

- a **straight section** upstream so the flow profile evens out,
- a **rigid, predictable run** so the meter sees consistent conditions,
- exact **connection locations** so the instrument ties in where the drawing says.

That is precisely what this spool provides — a controlled, meter-ready pocket in the line.

### The weldolet detail

The **WELDOLET DETALLE A** view is the branch connection where the meter's line ties into the main pipe — a **welded branch fitting**, chosen over a plain cut-and-weld tee because it distributes stress better under internal pressure.

- The detail sheet defines the **weld geometry and reinforcement** — a branch point is one of the highest-stress spots on any pressurized line.
- Get it wrong and the branch becomes a hidden failure point; get it right and the connection is as strong as the pipe itself.
- **Dual-unit dimensions** in both **inches and millimetres** (total height 7.359 in / 186.944 mm; width 22.25 in / 565.15 mm) — the standard for international fabrication and QA.
